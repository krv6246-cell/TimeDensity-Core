# Обзор проекта Time Density

## 1. Цель

`TimeDensity-Core` является центральным репозиторием системы Time Density. Его задача — удерживать основную модель, философию, терминологию и структуру проекта.

## 2. Что входит в систему

Проект состоит из нескольких уровней:

- ядро — `TimeDensity-Core`;
- визуальная и интерактивная демонстрация — `timeos`;
- игровая реализация — `Time-Density.`;
- экспериментальные площадки — `time-density-casino-core`, `td-modules`;
- вспомогательная документация — `timedensity-site`, `timedensity-faq`.

## 3. Основной принцип

Ядро определяет смысл и правила.
Реализации применяют эти правила в интерфейсах, приложениях и играх.
Эксперименты проверяют развитие системы.

## 4. Почему ядро важно

Без центральной модели проект превращается в набор разрозненных идей и визуальных прототипов. Ядро нужно, чтобы:

- зафиксировать понятия;
- сохранить терминологию;
- избежать путаницы между проектами;
- понять, что является фундаментом, а что — экспериментом;
- подготовить основу для сайта и приложений.

## 5. Базовая структура системы

```text
Time Density
├── Core
│   └── модель и философия
├── Prototype
│   └── интерактивная демонстрация
├── Game
│   └── применение в игровом контексте
├── Experiments
│   └── отдельные исследовательские идеи
└── Documentation
    └── сайт, FAQ, история и материалы
```

## 6. Рекомендация по развитию

На ближайшем этапе важно:

1. зафиксировать текущую версию парадигмы;
2. собрать базовый словарь терминов;
3. отделить ядро от приложений;
4. определить, какие версии являются актуальными;
5. подготовить структуру документации для сайта и разработки.

## 7. Вывод

`TimeDensity-Core` должен стать центром всей системы, вокруг которого строятся дальнейшие проекты, материалы и продукты.

Это обеспечивает единство идеи, ясность структуры и устойчивость развития.
