# Философское ядро

Этот каталог содержит смысловую основу парадигмы Time Density.

## Основной документ

- [core.md](core.md) — определение Time Density, центральная идея и основной цикл трансформации.

## Основной цикл

```text
Рассеяние → Потенциал → Резонанс → Сжатие → Point Zero → Новая форма → Отражение → Новый цикл
```

Философское ядро описывает общую модель перехода от рассеянного потенциала к согласованной форме. Оно является основой для дальнейшей разработки терминологии, архитектуры сайта, приложений и игровых механик.

## Статус

Документ является текущей рабочей формулировкой. Он может уточняться и расширяться по мере появления новых версий парадигмы и практических результатов.
