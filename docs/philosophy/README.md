# Философское ядро

Этот каталог содержит смысловую основу парадигмы Time Density.

## Основные документы

- [core.md](core.md) — определение Time Density, центральная идея и основной цикл трансформации.
- [modes.md](modes.md) — три режима: Potential Mode, Point Zero и Reflection Mode.
- [universal-compression-pattern.md](universal-compression-pattern.md) — универсальный паттерн сжатия и перехода.
- [resonator.md](resonator.md) — человек как резонатор.
- [validation.md](validation.md) — критерии проверки парадигмы через реализацию.

## Основной цикл

```text
Рассеяние → Потенциал → Резонанс → Сжатие → Point Zero → Новая форма → Отражение → Новый цикл
```

Философское ядро описывает общую модель перехода от рассеянного потенциала к согласованной форме. Оно является основой для дальнейшей разработки терминологии, архитектуры сайта, приложений и игровых механик.

## Принцип проверки

Каждый проект должен показывать, какой режим он исследует, какой процесс резонанса или сжатия моделирует, где находится `Point Zero` и как происходит переход в новое состояние.

## Статус

Документы являются текущей рабочей формулировкой. Они могут уточняться и расширяться по мере появления новых версий парадигмы и практических результатов.
